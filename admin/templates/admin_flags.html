Device Flags —

Anyone may register as many accounts as they like. When a signup or login shares a device or an IP with an existing account it is recorded here — never blocked. Open Info on any row for the full picture.

Auto-Ban

When enabled, users logging in from a device associated with a banned account are automatically banned. Disabled by default — review the flags below first.

Email / Password Sign-up

When enabled, visitors can register a new account with an email and password. Turn off to close self-service sign-ups for the whole fleet. On by default.

GitHub Sign-up

When enabled, visitors can sign up with GitHub. Off by default; the GitHub flow must be configured before this has any effect. Turning both sign-up options off means no new accounts can be created.
