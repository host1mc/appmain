What Applies When

Every control here is stored in the database, not the environment, so it takes effect on both panel instances within a few seconds of saving.

  • Immediately — feature switches and the maintenance notice: the panel re-reads them on request.
  • On next deploy — memory, CPU and disk. A running container keeps the allocation it was created with; the node applies the new figures to containers made after the change.
  • On next create — servers per account. Lowering it below what an account already has never deletes anything; that account simply cannot create more until it is under the new limit.

A control that has never been changed has no row at all and follows its built-in default, shown beside each switch.
