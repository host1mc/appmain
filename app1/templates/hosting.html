Free managed hosting for whatever you write — Node.js, Python, Ruby, Go, PHP or Bun. Upload your code, set the start command, and we run it around the clock.

What you get

Six runtimes

Node.js, Python, Ruby, Go, PHP and Bun. Discord bots, Telegram bots, web services, scrapers, schedulers — if it runs as a long-lived process, it runs here.

Pin your version

Several versions per runtime — Node 18 to 24, Python 3.10 to 3.13, Go 1.21 to 1.24, and so on. Dependencies install from your manifest. No Docker knowledge needed.

Token-safe by design

Tokens and environment variables are encrypted before storage, decrypted only in memory, and never displayed back to a browser or written to a log.

Runs unattended

Once deployed, there is nothing to restart or patch. If your app crashes, it comes back; if it needs attention, you get told.

Free, like the rest

The hosting is genuinely free. Running costs are covered by advertising on the public pages — no premium paywall. Free accounts stay live with a one-click weekly renewal from your console.

Deploy from the panel

A single console manages containers, environment variables, start commands and logs — a new app is minutes away.

How it works

  1. Write your app. Anything that runs as a long-lived process in one of the six runtimes — a Discord or Telegram bot, a web service, a scheduled job. If you already run it locally, you are ready.
  2. Upload it in the panel. Paste your code, add your dependency manifest — package.json, requirements.txt, Gemfile, go.mod — and tell us the start command.
  3. We keep it online. The runtime installs dependencies, starts your app, and supervises it. Crashes restart, and the panel shows live logs.

Runtimes

Six are live today: Node.js (18, 20, 22, 24), Python (3.10–3.13), Ruby (3.1–3.4), Go (1.21–1.24), PHP (8.1–8.4) and Bun (1.x). Pick the runtime and version in the panel; every one deploys the same way.

Availability

Hosting is open. Create an app from the panel, pick a runtime and version, set your start command and deploy — the first one is minutes away, and it stays free while the platform is in active development.

To follow new runtime launches and get help, join our Discord or the contact page.
