Setup guide

You make the bot in Discord’s developer portal, invite it to your server, then paste a few IDs into our panel. From there, pick your path: let us run a live Minecraft status embed for you (step 5), or upload your own app — Node.js, Python, Ruby, Go, PHP or Bun — and we run that instead (step 7). 01

Create a Discord application

Open the Discord Developer Portal while logged into the Discord account that owns (or can manage) your server.

  1. Click New Application.
  2. Name it something members will recognise — for example Survival Status.
  3. Accept the terms and create it.
02

Turn it into a bot and copy the token

An application is not a bot until you add the Bot user. The token is the password our engine uses to post the embed. Treat it like a password.

  1. Open the Bot tab in the left sidebar.
  2. Click Reset Token / Copy and store the token somewhere private for a moment.
  3. Under Privileged Gateway Intents, you do not need Message Content, Presence, or Server Members for a status embed. Leave them off unless you later use keyword replies that require them.
Never share the token. Paste it only into our panel. We encrypt it before storage, never send it back to the browser, and never log it. If it leaks, reset it in the Developer Portal and paste the new one.
03

Invite the bot to your Discord server

The bot must already be in the server before our engine can post.

  1. Open OAuth2 → URL Generator.
  2. Scopes: tick bot.
  3. Bot permissions: View Channels, Send Messages, Read Message History, and Embed Links. Do not grant Administrator.
  4. Copy the generated URL, open it, pick your server, and authorise.
View Channel Send Messages Read History Embed Links
04

Copy the guild ID and channel ID

Discord calls a server a guild. You need two snowflake IDs so the engine knows where to post.

  1. In Discord, open User Settings → App Settings → Advanced and turn on Developer Mode.
  2. Right-click your server icon → Copy Server ID. That is the guild ID.
  3. Right-click the status channel (a text channel you are happy to keep as one live card) → Copy Channel ID.
05

Point it at the Minecraft server

For the hosted status embed. Uploading your own bot instead? Skip to step 7.

We only query the public status endpoint. No RCON, FTP, plugin, or whitelist for our IP is required — the same query a multiplayer client uses when it lists the server.

Java Edition

Hostname or IP, port usually 25565. Edition: Java.

Bedrock

Hostname or IP, port usually 19132. Edition: Bedrock.

If the server is offline, the embed flips to your offline wording. When it comes back, it flips back on its own.

06

Create your free account, paste, start hosting

  1. Register with a Gmail or Outlook address and verify the 6-digit code.
  2. Open a bot slot. Paste the token, guild ID, channel ID, Minecraft address, and port.
  3. Design the card in the visual builder (title, colour, fields, player list). Preview it before you save.
  4. Save, then Start Hosting. The engine picks the bot up on the next tick and posts the first embed. After that it only edits that message.

Minimum refresh is 15 seconds. 60 seconds is enough for almost every server. You can close the browser — hosting does not run on your PC.

07

Choose the package folder and startup file

For your own app in any of the six runtimes — Node.js, Python, Ruby, Go, PHP or Bun. See App Hosting for versions and limits.

If your app lives in a subfolder, open the file list first. Click Pkg Install beside the manifest in that folder and the panel remembers the directory for future installs, so the next restart runs the install from there before your app starts.

Node.js & Bun

Use package.json to set the install location, then click your entry file and press Startup. That turns the file into the container command, for example node index.js, bun run index.ts, or cd app && npm install && node src/index.js.

Python, Ruby, Go & PHP

Same pattern with your own manifest — requirements.txt, Gemfile or go.mod. Install it from the folder that contains it, then choose the file that launches your app: main.py, main.rb, go run . or main.php.

?

If something does not appear

  • No embed. Confirm the bot is online in the member list, has the four permissions on that channel, and the IDs have no extra spaces.
  • Always offline. Check the edition (Java vs Bedrock) and that the address is the public one players use, not localhost.
  • Token error. Reset the token in the Developer Portal and paste the new one. An old token cannot be recovered from our panel.
  • Still stuck. Contact us or ask in the Discord community. Do not paste your token there.
